## 数据口径与限制

- 所有率值均为原始研究报告值；未自行合并。唯一汇总值来自 2026 年系统综述/Meta 分析 [1]。
- 非急性/慢性的时间定义在各研究中不一致；本汇报采用“非急性 >24 h、慢性 >1 个月”的工作定义，并保留原始界值。
- 病例为已发表文献病例，示意图由作者绘制，**不是患者原始影像**。
- 解剖/技术/病例示意图用于教学，不用于诊断或手术规划。
- 本汇报为文献综述，不构成临床指南；具体决策需多学科讨论。
