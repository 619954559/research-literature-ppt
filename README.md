# 文献调研与学术 PPT 自动化工作区 (Research Literature & PPT Workspace)

本仓库由 **dsh-superagent** 驱动，用于全自动执行：
- 📚 **文献检索与证据提取** (literature/): 调用 PubMed / EuropePMC / OpenAlex / bioRxiv / arXiv 等数据库检索论文、下载全文 PDF 并生成结构化文献综述。
- 📊 **组会汇报与学术 PPT 制作** (slides/): 基于检索到的文献或实验结果自动生成可编辑的 .pptx 演示文稿、图表及演讲备注。
- 🧬 **生信与临床统计分析** (eports/ & data/): 差异表达、富集分析、生存分析及科研绘图。

## 目录结构
- literature/ — 检索到的文献汇总表、全文 PDF、阅读笔记与综述 Markdown
- slides/ — 自动生成的 .pptx 课件与配图
- eports/ — 深度研究与分析报告
- data/ — 原始数据与分析结果表
